# StudentTaskManager – Mobile App Wireframe

## Project Description
StudentTaskManager is a mobile application wireframe designed to help students organize and manage their daily tasks.

## Objectives
- Design a simple and user-friendly mobile interface.
- Understand basic UI/UX design principles.
- Create low-fidelity wireframes for a mobile application.

## Screens Designed

1. **Login Screen** – User login interface.
2. **Home Screen** – Displays tasks and navigation.
3. **Add Task Screen** – Allows users to add new tasks.
4. **Task Details Screen** – Displays task information, priority and status.
